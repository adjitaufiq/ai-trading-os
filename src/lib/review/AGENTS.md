- Trade review (src/lib/review): deterministic compliance checks (compliance.ts, versioned by TRADE_REVIEW_VERSION) compare a CLOSED paper trade with the Trading Memory state at entry; an operator-only server function adds an LLM performance-analyst narrative and stores one append-only trade_reviews row per (trade_id, version). Why: review is feedback, never a signal, rule change or optimizer.
- Performance intelligence (src/lib/review/performance.ts) is a pure, descriptive aggregation of CLOSED paper trades joined with immutable trade_reviews, one data source at a time, with per-group MIN_SAMPLE sufficiency flags. Why: performance analysis explains history; it never feeds signals, rules or parameters.
