- cloud tables execution_config / execution_agent_status / execution_audit_log hold configuration and observability only; config changes go solely through the admin-checked update_execution_config RPC (trigger audits every change), and the VPS agent pulls config / pushes heartbeat+events via HMAC-signed /api/public/agent/* (EXECUTION_AGENT_SECRET), fail-closed when config is missing or stale. The cloud can halt or set limits but never arm a host not started with EXECUTION_MODE=DEMO_STRESS_TEST and never reaches the broker. Why: remote control without a cloud→broker path.
