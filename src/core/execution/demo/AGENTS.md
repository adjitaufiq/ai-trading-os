- DemoExecutionBridge (this dir) runs only in engine-host when EXECUTION_MODE=DEMO_STRESS_TEST (default REAL_DISABLED), forwards only approved paper opens (READY + plan PLANNED + M4 APPROVED), validates DEMO mode + login/server whitelist, enforces DEMO_RISK_PROFILE, kill switch and one order per signal_id with write-ahead append-only log. Why: demo stress test needs real fills without any real-account path.
- Shadow Guard (src/core/execution/shadow/ShadowGuard.ts) sits between every approved intent and the demo bridge, and also wraps the demo gateway port so sendOrder is unreachable while shadow is active; shadow is ON unless SHADOW_MODE=OFF with EXECUTION_MODE=DEMO_STRESS_TEST, every attempt is an append-only shadow record, and duplicate/SL/TP/emergency-stop protections cannot be disabled. Why: a UI bug, wrong config, restart or reconnect must never reach a broker send.
